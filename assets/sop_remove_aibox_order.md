# SOP 详情页：移除独立「AI 提炼」框工单（v2.12）

## 背景（已核实）
- 详情页 `src/components/sop/SopDocDetailBody.tsx` 当前同时存在两个区块：
  1. 独立的「✨ AI 提炼」边框框：读 `ai_status` / `ai_summary`，在 ai_status≠done 时显示"AI 提炼暂不可用，可直接查看原文或由上传人手动补充内容"。
  2. 「内容摘要」区：读 `content_excerpt`，空时显示"暂无正文摘录，若来源为飞书文档可在上传后自动提炼后补充"。
- 用户明确要求：**去掉独立的「AI 提炼」框**，只保留一个摘要区。
- 视觉/OCR 能力本轮仍不可用（公司审批中），所以图片类文档摘要仍为空属正常；本工单不解决摘要内容，只解决 UI 冗余与文案。

## 本轮范围
- 仅改前端详情页组件；不做 OCR、不改后端、不改上传逻辑、不删数据、不插示例、不 push main、不 deploy。
- 分支 feat/sop-management，dev/预览库。

## 具体任务
文件：`src/components/sop/SopDocDetailBody.tsx`

1. **整段删除**「✨ AI 提炼」那个独立边框区块（含 done / processing / 暂不可用三态的整块 JSX）。删除后页面不再出现该提示框。
2. **保留唯一的「内容摘要」区**（读 content_excerpt）：
   - 有 content_excerpt 时正常展示；
