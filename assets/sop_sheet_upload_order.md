# SOP 上传支持表格文件工单（v2.14）

## 需求
SOP 文档上传目前只接受 PDF/Word/PPT/txt/md/图片，表格（.xlsx/.xls/.csv）会被提示「类型不支持，已忽略」。现需**新增表格格式上传，并自主配套「展示」与「内容识别/摘要」形式**，做到上传后能正常看、能被检索/生成摘要。

## 范围
- 分支 feat/sop-management，仅 dev/预览库；不 push main、不 deploy、不碰生产、不插示例数据、飞书只读。
- 涉及前端上传/详情、文件类型与存储、服务端解析、（如有）数据库字段。

## 任务
### 1. 上传入口
- 本地上传支持 `.xlsx`、`.xls`、`.csv`（更新拖拽区 accept、提示文案「…·表格（xlsx / xls / csv）」、前端类型白名单与校验），不再忽略表格。
- 维持批量、单次上限等既有规则；大文件给必要的大小/失败提示。

### 2. 存储与类型
- 复用现有文件存储（私有桶 sop-files + 签名URL）模式；为表格设置清晰的 file_kind/mime（如 `sheet`/`xlsx`），与 image/pdf/doc 区分。
- 保留原始文件可下载。

### 3. 内容识别（重点）
- 上传/入库时解析表格为文本，写入文档正文/可检索字段（沿用现有 content_body / content_excerpt 体系），使其能参与列表检索与后续自动摘要：
  - 多 sheet：每个 sheet 标注名称，按「表头 + 行」输出；单元格做基础裁剪/空值处理；超大表给出截断上限并标注「共 N 行，展示/提取前 M 行」。
  - CSV：正确处理编码（兼容 UTF-8 / GBK）与分隔符。
- 技术选型（如 SheetJS/xlsx、服务端解析等）由你按工程现状决定；注意仅在服务端解析不可信文件，控制内存。

### 4. 详情页展示
- 表格类文档在「正式内容」区以**表格形式**清晰展示（不要只给一个下载链接）：
  - 渲染为带表头、斑马纹/边框、可横向滚动的 HTML 表格；多 sheet 提供 sheet 切换；沿用 dark/light 主题变量。
  - 行数/列数较多时做合理的高度限制与纵向滚动、必要的「前 M 行」截断提示，并保留「下载原表格」。
  - 不要把表格转成图片或长 PDF（除非确有必要并说明）。

### 5. 兼容
- 不破坏 image/pdf/Word/PPT/txt/md 既有上传、PdfViewer、内容摘要区、状态徽章、查看原图等能力。
- 在线链接（飞书/腾讯文档）路径如受影响需一并兼容（飞书多维表格/在线表格若遇到，按只读抓取，取不到则正常兜底，不要报错）。

## 验收
1. ts-check / lint（改动文件0新增告警）/ build 全绿；必要的单元/接口自测通过。
2. 实际上传一个 .xlsx（建议多 sheet）与一个 .csv：
   - 不再提示类型不支持；文档成功创建、类型正确、可下载原文件；
   - 详情页以表格形式正确展示（表头、sheet切换、滚动、主题）；
   - 文本已写入可检索字段，列表搜索表格内关键词能命中；content_excerpt 体系不被破坏。
3. 超大/空表/异常编码有合理兜底，不白屏、不崩。
4. 既有 PDF(X500)/图片/Word 等上传与详情展示回归正常。
5. 测试中产生的临时文件/数据用例清理还原，dev 库不留垃圾。
6. 完成后自动重启预览并返回 preview_url。

## 交付
返回：改动文件清单、采用的解析与展示方案、自测证据（含真实 xlsx/csv 验证）、preview_url。
