# 百应 M2 补丁：账号自动带出 + 频率支持分钟/小时

分支：feat/dy-buyin-spike。仅 dev，不 deploy，不插假数据。在已完成的 TaskConfigPanel / buyin-session 基础上改。

## 1. 账号/达人自动带出当前扫码账号
- 登录成功后，配置区「账号 / 达人」自动带出当前会话账号，而不是要求手填。
- 数据来源：现有 buyin 会话状态接口返回的账号标识（status 里的 accountHint / 识别账号，cookie 已在后端，不要把 cookie 明文返给前端）。
  - 若会话能给出可读账号名/达人ID 就分别填入 by_account / by_kol_id；若只能给出 hash 标识，则填入 by_account 占位并标注"来自当前登录账号"。
- 手动输入框保留，作为"想采集其他达人/账号"的覆盖项；留空=采集当前登录账号。加一句说明文字。
- 未登录 / 重新登录切换账号后，带出值要随之更新。

## 2. 获取频率支持按分钟/小时
频率下拉改为：
- 按分钟：显示"每 N 分钟"，N 输入，设下限（建议最小 5 分钟，默认 15），并提示"高频可能触发百应风控 11001；分钟级为轮询刷新，出数仍按小时/天聚合"。
- 按小时：每 N 小时（默认 1，范围 1-23）。
- 每天：保留，配合"获取时间"时刻。
- 每周：保留，可选星期（如本版来不及可先默认周一并备注）。
- 自定义间隔（天）：保留。
- 仅手动：保留。
- 选择分钟/小时时，"获取时间（时刻）"字段可隐藏或标注不适用；选每天/每周时用时刻。

## 3. 存储与接口
- buyin_tasks 的 frequency 增加 minute/hour 取值，新增 interval_value（间隔数值）等；若原字段 interval_days 可复用/改名，请做兼容，不要破坏已保存任务读取。
- 校验：分钟 N>=下限、小时 1-23；非法值前后端都拦截。
- 已保存任务列表正确显示新频率文案（如"每 15 分钟"）。

## 自检（必须）
- 构建通过、无类型错误；
- 登录后账号自动带出，切换/重登后更新，留空走登录账号、手填可覆盖；
- 六种频率可选、间隔输入与下限校验生效、列表/编辑回显正确；
- 不影响其他页面、/sop 与既有任务数据。

## 交付
改动清单、字段/接口变更、构建结果、账号带出与频率校验实测结论。
